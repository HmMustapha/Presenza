## 📌 About The Project

**Presenza** is a mobile application designed to simplify and digitalize university attendance management.

The application uses QR Code technology to provide a fast, efficient, and reliable way to record student attendance. Professors can generate QR codes for their courses, while students can scan them to register their presence.

Presenza aims to replace traditional paper-based attendance methods with a modern digital solution.

## ✨ Key Features

- 📱 **Mobile Application:** Easy-to-use and intuitive interface.
- 🔳 **QR Code Generation:** Professors can generate QR codes for their sessions.
- 📷 **QR Code Scanning:** Students can scan codes to register attendance.
- 👨‍🏫 **Professor Management:** Manage courses and attendance sessions.
- 🎓 **Student Management:** Simplify student attendance tracking.
- 📊 **Attendance Records:** Keep attendance data organized.
- 🔒 **Secure Registration:** Improve attendance tracking reliability.

## 🎯 Project Objectives

- Eliminate manual attendance registration.
- Reduce errors and save classroom time.
- Simplify attendance management for professors.
- Provide students with a convenient check-in experience.
- Digitalize university administrative processes.
